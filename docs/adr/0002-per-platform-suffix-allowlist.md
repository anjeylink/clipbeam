# The Media Proxy allowlist is per-Platform, with suffix rules for Threads and hop-by-hop redirect checks

`/api/download` only fetches allowlisted hosts so it can't be used as an open proxy. X's CDN hosts are fixed (`video.twimg.com`, `pbs.twimg.com`) and stay exact matches, but Threads media is served from regional edges whose hostnames vary (`instagram.flwo3-1.fna.fbcdn.net`, `scontent.cdninstagram.com`, …) and a CDN may 302 between them. So the allowlist is grouped per Platform: X keeps exact hosts, Threads allows any HTTPS host ending in `.fbcdn.net` or `.cdninstagram.com` (dot-anchored, so `evilfbcdn.net` and `fbcdn.net.evil.com` don't match). The proxy no longer lets `fetch` follow redirects on its own: each `Location` is re-checked against the same allowlist before it's followed, capped at a few hops. A tighter per-edge regex was rejected because it would break whenever Meta renames an edge.
